# Etap 20 — diagnostyka zapisanej analizy, bez nowego wywołania AI

## Cel i granice

Etap 19 zakończył rzeczywiste wyszukiwanie i import PDF-u, ale dalsza ekstrakcja
zatrzymała się na ogólnym błędzie cytatu. Dotychczas panel nie pozwalał ustalić,
która reguła i fragment spowodowały blokadę. Ten przyrost dodaje taki odczyt.
Nie zatwierdza strategii, nie zmienia cytatów, nie wznawia zadania i nie wywołuje
modelu. To wsparcie AJ-05/AJ-08, a nie ukończenie całego badania.

## Implementacja

- `GET /api/astra/extraction-diagnostics?id=<material-id>` wymaga sesji
  użytkownika i materiału należącego do tego użytkownika. Brak dostępu daje
  401/404; błędy wewnętrzne nie ujawniają SQL, sekretów ani odpowiedzi dostawcy.
- Odczytuje wyłącznie zapisaną operację `extract:v1` dla bieżącej rewizji
  i punktu postępu materiału. Nie przeszukuje dowolnie odpowiedzi innych zadań.
- Porównuje cytaty z fragmentami faktycznie dostępnymi dla tej partii czytania,
  z dotychczasową obsługą wyłącznie różnic białych znaków. Nie korzysta
  z późniejszych, jeszcze niewysłanych fragmentów jako potwierdzenia.
- Raport pokazuje regułę, deklarowany cytat, ID i położenie fragmentu oraz
  ewentualne dokładne wystąpienie w innym odczytanym fragmencie. Wskazówka
  lokalizacji nie stanowi zaakceptowanej zmiany ID.
- Liczniki obejmują cały sparsowany wynik; szczegóły ograniczono do 20
  problemów, wskazówki do 3 lokalizacji. Niepełność jest jawnie oznaczona.
  Wyszukiwanie wskazówek ma także ograniczenie objętości skanowanego tekstu.
- Nie zwraca pełnej odpowiedzi dostawcy, promptu, billing metadata ani kluczy.
  API nie ma metody POST/DELETE, zapisów D1, kolejki lub transportu AI.
- Podgląd: Research → Materiały → „Treść i wersje źródła” →
  „Sprawdź zapisaną analizę — bez AI”. Tekst jest renderowany jako tekst React,
  nie wykonywany HTML lub instrukcja z materiału.

## Dowody lokalne

298/298 testów witryny, w tym 11 nowych: odczyt bez zapisów, prawidłowe cytaty,
różnice białych znaków, wymyślone treści, błędne ID, obcy użytkownik, rewizja,
postęp, niepewna/niepełna odpowiedź, limity oraz autoryzacja i bezpieczne błędy API.
TypeScript, lint nowych plików i pełny build: PASS. Build zachowuje ostrzeżenia
dużych chunków i niepełnej statycznej klasyfikacji tras. W starszym
`discovery-desk.tsx` pozostają trzy błędy React hooks i ostrzeżenie nieużywanej
ikony. Porównano poprzedni commit i wersję zmienioną tym samym ESLintem
(z wyłączoną zastaną regułą `no-explicit-any`): identyczne komunikaty,
zero nowych ustaleń. Nie jest to deklaracja czystego lint całej aplikacji.
