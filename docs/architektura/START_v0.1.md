# AstralJet — dokumentacja do wspólnej pracy

**AstralJet = cały system. ASTRA Pro Trading Lab = badanie i testowanie strategii.**

Wersja 0.1, 19 września 2026. Dokumenty są propozycją organizacji i zakresu budowy na podstawie dwóch zdjęć oraz wcześniejszych ustaleń. Nie stanowią wdrożenia opisanych modułów.

- [Struktura AstralJet — 19 kart ról, zadania, zależności i uprawnienia](ASTRALJET_STRUKTURA_v0.1.md)
- [ASTRA Pro Trading Lab — szczegółowe zadania badania i testowania](ASTRA_PRO_TRADING_LAB_v0.1.md)
- [Role i zależności jako tabela CSV](ASTRALJET_ROLE_I_ZALEZNOSCI.csv)
- [Istniejąca karta projektu w Notion](https://www.notion.so/3a6cb4db395681da9b3efe36e30d1d85)

Pierwszy proponowany rezultat budowy: jedna dostarczona strategia → kompletne reguły → dane → zamrożony plan → test → przegląd → odtwarzalny raport. Wyszukiwanie strategii zasila ten proces; wykonanie DEMO pozostaje osobnym modułem.

Pracujemy wspólnie: omawiamy ustalenia; drobne poprawki wykonuję sam, ważne decyzje uzgadniamy przed wykonaniem. W pierwszej rozmowie wdrożeniowej wybieramy strategię i ustalamy zakres jej badania.
